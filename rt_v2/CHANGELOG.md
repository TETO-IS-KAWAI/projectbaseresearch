# 변경 내역

## [2.0.0] — 2026-11-23

HI 21cm 전파망원경 v2.0 — 화면을 새로 만들고, 관측 데이터만으로 나선팔을 추론합니다.

### 내려받기
| 파일 | 설명 |
|---|---|
| `RWA_HI21cm-2.0.0-setup.exe` | **설치 파일 (권장).** 관리자 권한 없이 내 계정에 설치되고, 시작 메뉴·바탕화면 바로가기와 제거를 지원합니다. 설치 첫 화면에서 '모든 사용자'를 고를 수도 있습니다. |
| `RWA_HI21cm-2.0.0-portable-win64.zip` | 휴대용 판. 압축을 풀고 `RWA_HI21cm.exe` 를 실행합니다 (USB 로 옮겨 쓰기 좋음). |
| `SHA256SUMS.txt` | 내려받은 파일이 온전한지 확인하는 해시. |

요구 사항: Windows 10/11 64비트. 파이썬 설치는 필요 없습니다.

> 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 이 "알 수 없는 게시자" 경고를 띄울 수 있습니다.
> **추가 정보 → 실행** 을 누르면 됩니다. 소스 코드는 이 저장소에 모두 공개되어 있습니다.

### 새로워진 점
- **새 화면** — 홈·관측·하늘 지도·은하 지도·관측 기록·설정·정보 7개 페이지. 다크/라이트 테마,
  Ctrl+K 명령 팔레트, 단축키, 픽셀로 조립되는 제목과 시작 화면.
- **관측** — 적경·적위(소수·시분초·도분초), 방향 프리셋(은하면·지금 천정), 현재 고도 미리보기,
  처리 단계(IQ → FFT → 도플러 → T_b → 피크 → 거리 → 저장) 실시간 표시, 스펙트럼 확대·이동·십자선.
- **하늘 지도** — 몰바이데 / 드래그로 돌리는 천구, 은하·적도 좌표, 관측지에서 안 뜨는 하늘과
  지금의 천정·지평선 표시, FITS·MOC 내보내기.
- **은하 지도** — 세 가지 보기
  - *관측 데이터로 추론*: 배경 나선팔 없이 관측 피크만 찍고, 로그 나선 허프 변환으로 팔을 찾아냅니다
    (팔 개수·피치각 자동, 근/원거리 모호성 처리, 허프 공간 미니맵).
  - *문헌 모델 예측*: Hou & Han (2014) 근사 팔과, 관측한 시선마다 예상 교차점·예상 v_LSR.
  - *겹쳐 보기*: 추론한 팔과 문헌 팔 비교. 합성 데이터로 체험도 가능.
- **관측 기록** — 정렬·검색, 피크 보기, 하늘 지도에서 보기, 같은 방향 재관측, 삭제.

### 물리·정확도
- 은하 회전 상수를 논문과 일치: R₀ = 8.15 kpc, Θ₀ = 236 km/s (Reid et al. 2019).
- 운동학적 거리: 물리적으로 불가능한 음수 거리('금지 속도')를 버리고, 외부 은하는 유일해,
  조감도는 은하면 투영 거리(d·cos b)로 찍습니다.
- MOC 내보내기의 HEALPix 픽셀 번호 체계(RING→NESTED) 오류 수정.

### 성능·하드웨어
- 그래픽 카드(GPU)로 지도를 그리고, 오래된 내장 그래픽도 가속을 씁니다. 설정 → 하드웨어에서
  사용 중인 장치를 확인하고 끌 수 있습니다.
- 관측 계산은 별도 프로세스가 다른 CPU 코어에서 처리해, 계산 중에도 화면이 끊기지 않습니다.
- 지도 그리기 최적화 (은하 지도 드래그 약 60 fps).

### 보안
- 앱 화면은 앱 폴더 밖으로 이동할 수 없고, 외부 접속·인라인 스크립트를 막는 콘텐츠 보안 정책을 씁니다.
- 파일 경로·형식 검사, 권한 요청(카메라·위치 등) 거부, 캐시·쿠키를 디스크에 남기지 않음.

### 알려진 한계
- 밝기온도는 잡음원·hot/cold 보정이 없는 **상대값**입니다.
- 빔(~20°)과 속도 오차 때문에 실제 관측만으로 개별 나선팔을 분해하기는 어렵습니다
  (예: PreBetaTwo 데이터는 피크 24개 중 4개만 은하면 거리로 사용 가능 → '추론 불가').
